# havox-international
Official website and automated enrollment portal for Havox International's AI and communication training programs.

Havox International | Official Website & Enrollment Portal

Welcome to the official web repository for Havox International, a premium training and AI automation company.

This project serves as the global landing page and automated enrollment portal for our diverse range of training programs, catering to students, professionals, and executives.

**Core Features**

Modern UI/UX: Built with a lightweight, responsive glass-morphism design using HTML and Tailwind CSS.

Zero-Cost Automation Backend: Utilizes Google Apps Script to process form submissions without expensive third-party subscriptions.

Automated CRM: Instantly logs new student applications into a secure Google Sheets database.

Smart Email Onboarding: Automatically triggers a customized welcome email to the applicant upon submission.

WhatsApp Integration: Redirects the user directly to a pre-filled WhatsApp message for instant communication with the Havox team.

**Featured Programs**

Havox AI Program: Automation & AI engineering for student cohorts.

Junior Vox: Speaking & presentation fundamentals for students.

VoX-Publica: The art of public speaking and commanding a room.

Havox-ELITE: Corporate training for executive language and high-stakes influence.

**Technology Stack**

Frontend: HTML5, Tailwind CSS, Vanilla JavaScript

Backend / Database: Google Apps Script, Google Sheets API, Gmail API

Hosting: GitHub Pages
